# tparisotto.github.io

Personal portfolio of Tommaso Parisotto, served by GitHub Pages at <https://tparisotto.github.io/>.

A single static page with no build step or JavaScript:

- `index.html`: the page
- `assets/css/portfolio.css`: all styles
- `assets/fonts/`: self-hosted Figtree and Newsreader (SIL Open Font License)
- `images/`: portrait, social preview image, favicons
- `kotoba/`: redirects `/kotoba/` to the hosted Kotoba app

To preview locally, run `python3 -m http.server` and open <http://localhost:8000>.
